- ✅ 推荐难度适中、审稿快的替代期刊
- ✅ 提供科研图片生成 Prompt
- ✅ 准备完整的投稿材料包

**3 分钟完成投稿准备，让您专注于研究本身！** ⚡

## ⚡ 快速开始

### 方式 1: 直接对话（最简单！）

只需在对话中说：

```
我要投稿到 [期刊名称]，稿件在 [文件路径]
```

**示例：**
```
我要投稿到 Nature Communications，稿件在 ./my_paper.docx
```

系统会自动：
1. 读取并分析您的稿件
2. 搜索期刊要求
3. 生成检查报告
4. 提供修改建议
5. 生成 Word 格式输出

---

### 方式 2: 使用命令行工具

```bash
# 检查稿件格式
python manuscript_formatter.py <稿件路径> "<期刊名称>"

# 推荐替代期刊
python journal_recommender.py "<期刊名称>" ["研究领域"]

# 生成 Word 文档
python word_processor.py
```

**示例：**
```bash
python manuscript_formatter.py sample_manuscript.md "Nature Communications"
python journal_recommender.py "Nature" "machine learning"
```

## 🎯 主要功能

### 功能 1: 稿件格式检查 ✅

**检查内容**：
- 📋 结构完整性（标题、摘要、章节、参考文献）
- 📏 字数统计（总字数、摘要、各章节）
- 🖼️ 图表检查（数量、编号、引用）
- 📚 参考文献（格式、一致性、引用匹配）

**输出**：详细的检查报告 + 修改建议列表

---

### 功能 2: 期刊要求分析 🔍

**自动搜索**：
- 期刊官方 Author Guidelines
- 格式要求（字体、行距、页边距）
- 图片要求（分辨率、格式、尺寸）
- 参考文献格式
- 字数限制
- 特殊要求（声明、补充材料等）

**输出**：完整的期刊要求报告

---

### 功能 3: 智能期刊推荐 💡

**推荐标准**：
- ✅ 接受率高（>40%）
- ✅ 审稿周期短（<8 周）
- ✅ 研究领域匹配
- ✅ 影响因子适中
- ✅ 费用合理

**输出**：
- 6-10 个推荐期刊
- 详细对比表
- 投稿策略建议

**实际案例**：
- Nature Communications (接受率 7.7%)
  → 推荐 Scientific Reports (接受率 60%)
  → **成功率提升 8 倍！**

## 📚 使用教程

### 教程 1: 第一次投稿

**场景**：博士生，首次投稿SCI，不太了解流程

**步骤**：
1. 准备好稿件（Word/PDF/Markdown 均可）
2. 告诉系统："我要投稿到 [目标期刊]，稿件在 [路径]"
3. 查看格式检查报告，了解需要修改的地方
4. 查看期刊要求报告，了解详细规范
5. 根据建议修改稿件
6. 系统生成符合要求的 Word 文档
7. 下载投稿文件，在期刊网站提交

**预计时间**：1-2 天（vs 传统方式的 1-2 周）

---

### 教程 2: 被拒后转投

**场景**：稿件被 Nature Communications 拒稿，需要快速找替代期刊

**步骤**：
1. 告诉系统："推荐 Nature Communications 的替代期刊"
2. 查看推荐列表（6-10 个期刊）
3. 根据需求选择（快速发表/高接受率/低费用）
4. 告诉系统："帮我改成 Scientific Reports 格式"
5. 系统自动调整格式并生成新文档
6. 立即投稿到新期刊

**预计时间**：2-3 小时（vs 传统方式的 3-5 天）

---

### 教程 3: 需要生成图片

**场景**：论文需要流程图，但不会画图

**步骤**：
1. 查看 `image_prompts_library.md`
2. 找到对应的图片类型（如"研究流程图"）
3. 复制 prompt 模板
4. 填入您的具体内容
5. 使用 DALL-E/Midjourney 生成图片
6. 调整为期刊要求的格式（300 DPI, TIFF）
7. 告诉系统插入到 Word 文档

**预计时间**：30 分钟（vs 学习专业绘图软件的数周）
