## 📊 流程图类 (Flowcharts)

### 1. 研究流程图 (Research Workflow)

```
Create a professional scientific flowchart showing a research workflow with the following steps:
[在此处列出您的研究步骤]

Style requirements:
- Clean, academic style
- Use rectangular boxes for processes
- Use diamond shapes for decision points
- Use arrows to show flow direction
- Color scheme: Professional blues and grays
- Include labels in clear sans-serif font
- High resolution, suitable for publication
- White or light gray background
```

**示例：**
```
Create a professional scientific flowchart for a machine learning research workflow:
1. Data Collection
2. Data Preprocessing
3. Feature Extraction
4. Model Training
5. Model Validation
6. Performance Evaluation
7. Results Analysis

Style: Clean academic style, blue and white color scheme, suitable for Nature journal publication
```

## 🔧 使用说明

### 如何使用这些 Prompts：

1. **选择合适的类型**：根据您的研究领域和需求选择对应的 prompt 模板

2. **自定义内容**：将方括号 `[]` 中的内容替换为您的具体信息

3. **调整细节**：根据期刊要求调整风格说明（颜色、分辨率等）

4. **生成图片**：
   - 使用 DALL-E 3 (ChatGPT Plus)
   - 使用 Midjourney
   - 使用 Stable Diffusion
   - 使用其他 AI 绘图工具

5. **后期处理**：
   - 使用 Illustrator/Inkscape 添加精确标注
   - 调整分辨率至 300 DPI 或以上
   - 转换为期刊要求的格式（TIFF/EPS/PNG）

## 📋 期刊图片要求快速参考

### Nature 系列
- 格式：TIFF, EPS, PDF
- 分辨率：300-600 DPI
- 颜色：RGB（在线）或 CMYK（印刷）
- 尺寸：单栏 88mm，双栏 180mm

### Science 系列
- 格式：TIFF, EPS, PDF, AI
- 分辨率：≥300 DPI (照片), ≥500 DPI (组合图)
- 字体：Helvetica, Arial, Times

### IEEE
- 格式：TIFF, EPS, PDF
- 分辨率：≥300 DPI (彩色), ≥600 DPI (线图)
- 颜色：可用彩色（免费）

### Elsevier 期刊
- 格式：TIFF, EPS, PDF
- 分辨率：≥300 DPI
- 线宽：≥0.5 pt

### PLOS 系列
- 格式：TIFF, EPS, PDF
- 分辨率：300-600 DPI
- 尺寸：宽度不超过 17.35 cm

## 💡 Pro Tips

1. **描述要具体**：提供详细的元素描述，包括颜色、布局、标签

2. **指定风格**：明确说明"scientific illustration"、"technical diagram"等

3. **提及期刊**：在 prompt 中提到目标期刊名称，AI 会生成更符合该期刊风格的图片

4. **多次生成**：同一个 prompt 可能需要生成多次才能得到满意的结果

5. **组合使用**：AI 生成基础图形，然后用专业软件（如 Adobe Illustrator）进行精修

6. **保持一致性**：论文中的所有图片保持统一的视觉风格

## 📥 输出到 Word 文档

### 将生成的图片插入 Word：

1. **保存高分辨率版本**
2. **在 Word 中插入** → 图片 → 此设备
3. **设置图片格式**：
   - 右键 → 大小和位置
   - 锁定纵横比
   - 设置宽度（通常 8-16 cm）
4. **添加题注**：
   - 引用 → 插入题注
   - 选择"图"
   - 输入图片说明
